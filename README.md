# AWS S3 Static Website Hosting Project

## Overview

This project demonstrates hosting a static website using Amazon S3.

## Services Used

* Amazon S3
* IAM
* Git
* GitHub

## Project Workflow

VS Code
↓
Git
↓
GitHub
↓
Amazon S3
↓
Static Website Hosting

## Tasks Completed

* Created a static HTML website.
* Created an S3 bucket.
* Uploaded website files to S3.
* Enabled Static Website Hosting.
* Configured public access permissions.
* Applied bucket policy.
* Accessed the website using the S3 endpoint.
* Tracked source code using Git.
* Pushed code to GitHub.
* Updated and redeployed website content.

## Skills Learned

* Amazon S3
* Static Website Hosting
* Bucket Policies
* Git Fundamentals
* GitHub Workflow
* Website Deployment

## Outcome

Successfully deployed a static website on AWS S3 and managed the source code using Git and GitHub.
